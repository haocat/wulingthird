
 
 
# 五菱汽车车控 APP

本项目是基于 [hasscc/wuling](https://github.com/hasscc/wuling) 开发的五菱新能源**独立开源车控 APP**，无需 Home Assistant 环境，直接对接五菱/宝骏官方车联网接口，为车主提供一站式车辆控制与状态监控体验。

> 本项目原由 [wlsqqq/wuling-automotive-control](https://gitee.com/wlsqqq/wuling-automotive-control) 首发，现已转移至 GitHub 继续独立开发。如有侵权，会第一时间删除。

---

## ✨ 已实现功能

### 🔧 远程控制

| 功能 | 说明 |
|------|------|
| 锁车 / 解锁 | 一键远程上锁/解锁车门 |
| 空调控制 | 支持开启/关闭、温度调节、风速调节，以及快速制冷/快速制热 |
| 远程启动 | 远程启动车辆（点火授权） |
| 尾箱 | 远程开启后备箱 |
| 寻车 | 远程鸣笛闪灯，帮助停车场找车 |

### 📊 车辆状态监控

| 类别 | 数据项 |
|------|--------|
| 电量与续航 | SOC 电量、纯电续航、燃油续航、混动里程、剩余油量 |
| 电池 | SOH 健康度、温度范围、电压、电流、低压电池 |
| 里程 | 总里程、昨日里程、平均能耗 |
| 胎压 | 四轮胎压（bar）+ 轮胎温度 |
| 车门 | 每扇门开关状态 + 锁定状态，尾箱状态 |
| 车窗 | 每扇窗开关状态 + 开度百分比 |
| 灯光 | 前雾灯、左/右转向灯、示廓灯、远/近光灯 |
| 充电 | 充电状态、充电功率、剩余时间 |
| 温度 | 车内温度、空调温度、电机温度、逆变器温度 |
| 驾驶 | 档位、方向盘角度、刹车/油门踏板、钥匙状态 |
| 诊断 | 动力系统、发动机温度、ABS、动力转向故障检测 |
| 座椅 | 加热/通风状态 |
| 其他 | 哨兵模式、平均车速、智能驾驶开关 |

### 🗺️ 车辆位置

- 集成高德地图 WebView，实时显示车辆定位
- 支持一键跳转高德导航找车
- 支持分享车辆位置

### 📡 BLE 无感控车

- 蓝牙数字钥匙：从服务器获取 BLE 密钥并连接车载蓝牙
- RSSI 自动控车：靠近车辆自动解锁，远离自动上锁
- 可配置解锁/上锁 RSSI 阈值、持续时间、冷却时间
- 前台保活服务，后台运行
- 设备扫描：查看附近蓝牙设备信号强度

### ⚙️ 个性化配置

- API Token 绑定（DataStore 安全持久化）
- 主题设置：浅色 / 深色 / 跟随系统
- 自定义配色方案（主色、背景色、卡片色、文字色）
- 自定义背景图片 + 模糊 + 遮罩效果
- 卡片透明度调节
- 调试日志查看器（带分级过滤、复制、清空）
- 高德地图 Key 配置

## 📦 安装与使用

1. 从 [Release 页面](https://github.com/haocat/wulingthird/releases) 下载 APK
2. 安装后前往「我的」→「API Token」配置令牌
3. Token 需自行获取（抓包五菱/宝骏官方 App）
4. 建议使用授权手机号对应的 Token
5. 位置功能需自行配置高德地图 Web JS API Key
